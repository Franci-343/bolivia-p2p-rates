# Autenticación & Cabeceras HTTP

Todas las solicitudes a las rutas de tasas (/api/v1/rates/*) requieren una API Key activa:

Opción 1: Cabecera HTTP (Recomendada)
X-API-Key: bolivia_live_TU_CLAVE
Opción 2: Parámetro de Consulta
?apiKey=bolivia_live_TU_CLAVE
ℹ️
Control de Cuota: El plan libre asigna 10 RPM. Exceder la cuota retorna código 429 Too Many Requests.
GET /api/v1/rates/latest
Tasas consolidadas + bancos

Retorna el snapshot de mercado con el promedio ponderado, margen de spread y la cotización específica de cada entidad financiera boliviana (Banco Unión, BISA, BNB, Mercantil, Sol, etc.).

# Terminal / Bash curl -H "X-API-Key: bolivia_live_..." http://155.181.158.36:8080/api/v1/rates/latest
// JavaScript (Node.js / Navegador) const res = await fetch('http://155.181.158.36:8080/api/v1/rates/latest', { headers: { 'X-API-Key': 'bolivia_live_...' } }); const data = await res.json(); console.log('Compra USDT:', data.buyMarket.referencePrice, 'Venta USDT:', data.sellMarket.referencePrice);
# Python 3 (requests) import requests url = 'http://155.181.158.36:8080/api/v1/rates/latest' headers = {'X-API-Key': 'bolivia_live_...'} data = requests.get(url, headers=headers).json() print("Compra:", data['buyMarket']['referencePrice'], "Venta:", data['sellMarket']['referencePrice'])

# Códigos de Estado HTTP

Código Significado Motivo Común
200 OK Petición exitosa Retorna el objeto JSON con las cotizaciones.
401 Unauthorized No autorizado Falta `X-API-Key` o la clave no existe o está pausada.
429 Too Many Requests Límite excedido Superaste las 10 peticiones en 1 minuto.
500 Server Error Error interno Excepción no controlada en el servicio.

# Autenticación & Cabeceras

Todas las solicitudes a las rutas de tasas (/api/v1/rates/*) requieren una API Key activa. Puedes suministrarla mediante la cabecera HTTP estándar o a través de la URL:

Opción 1: Cabecera HTTP (Recomendada)
X-API-Key: bolivia_live_TU_CLAVE
Opción 2: Parámetro de Consulta (Query Param)
?apiKey=bolivia_live_TU_CLAVE
ℹ️
Rate Limiting (Control de Cuota): El nivel gratuito permite 10 peticiones por minuto (RPM) por cada llave. Si se excede la cuota en una ventana de 60 segundos, la API responderá con el código 429 Too Many Requests.
GET /api/v1/rates/latest
Tasas consolidadas + desglose bancario

Retorna el snapshot de mercado más reciente con el promedio general ponderado, margen de spread y la cotización específica de cada entidad financiera boliviana (Banco Unión, BISA, Banco Mercantil Santa Cruz, BNB, Banco Sol, etc.).

Ejemplos de Consumo:
# cURL (Terminal / Bash) curl -H "X-API-Key: bolivia_live_..." http://155.181.158.36:8080/api/v1/rates/latest
// JavaScript (Node.js / Navegador) const res = await fetch('http://155.181.158.36:8080/api/v1/rates/latest', { headers: { 'X-API-Key': 'bolivia_live_...' } }); const data = await res.json(); console.log('Compra USDT:', data.buyMarket.referencePrice, 'Venta USDT:', data.sellMarket.referencePrice);
# Python (requests) import requests res = requests.get('http://155.181.158.36:8080/api/v1/rates/latest', headers={'X-API-Key': 'bolivia_live_...'}) print(res.json()['buyMarket']['referencePrice'])

GET /api/v1/rates/buy

Lista detallada de las mejores ofertas activas de compra (usuarios que compran USDT pagando con BOB). Incluye límites y métodos de pago.

curl -H "X-API-Key: ..." http://155.181.158.36:8080/api/v1/rates/buy
GET /api/v1/rates/sell

Lista detallada de ofertas activas de venta (usuarios que venden USDT a cambio de BOB). Ideal para conocer el precio real de salida.

curl -H "X-API-Key: ..." http://155.181.158.36:8080/api/v1/rates/sell
GET /api/v1/rates/history

Serie histórica de cotizaciones guardadas en SQLite para análisis de tendencias, gráficas financieras o backtesting de algoritmos.

curl -H "X-API-Key: ..." http://155.181.158.36:8080/api/v1/rates/history

Códigos de Estado HTTP

Código Significado Motivo Común
200 OK Petición exitosa Retorna el JSON solicitado.
401 Unauthorized No autorizado Falta la cabecera `X-API-Key` o la clave no existe o está desactivada.
429 Too Many Requests Límite excedido Se superaron las 10 peticiones en la ventana de 1 minuto.
500 Server Error Error interno Excepción no controlada en el servidor.

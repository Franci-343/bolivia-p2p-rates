# Autenticación & Cabeceras HTTP

Todas las solicitudes a las rutas de tasas (/api/v1/rates/*) requieren una API Key activa. Puedes suministrarla mediante la cabecera estándar (recomendada) o mediante parámetro de consulta:

Opción 1: Cabecera HTTP (Recomendada)
X-API-Key: bolivia_live_TU_CLAVE
Opción 2: Parámetro de Consulta (Query Param)
?apiKey=bolivia_live_TU_CLAVE
ℹ️
Rate Limiting (Control de Cuota): El nivel gratuito asigna 10 peticiones por minuto (RPM) por cada llave. Si se supera la cuota en una ventana de 60 segundos, la API responderá con el código 429 Too Many Requests.
GET /api/v1/rates/latest
Tasas consolidadas + desglose bancario nacional

Retorna el snapshot de mercado más reciente con el promedio general ponderado, margen de spread y la cotización específica de cada entidad financiera boliviana (Banco Unión, BISA, Banco Mercantil Santa Cruz, BNB, Banco Sol, Banco Ganadero, etc.).

# Terminal / Bash curl -H "X-API-Key: bolivia_live_..." http://155.181.158.36:8080/api/v1/rates/latest
// JavaScript (Node.js / Navegador) const res = await fetch('http://155.181.158.36:8080/api/v1/rates/latest', { headers: { 'X-API-Key': 'bolivia_live_...' } }); const data = await res.json(); console.log('Compra USDT:', data.buyMarket.referencePrice, 'Venta USDT:', data.sellMarket.referencePrice);
# Python 3 (requests) import requests url = 'http://155.181.158.36:8080/api/v1/rates/latest' headers = {'X-API-Key': 'bolivia_live_...'} data = requests.get(url, headers=headers).json() print("Compra:", data['buyMarket']['referencePrice'], "Venta:", data['sellMarket']['referencePrice'])

# Códigos de Estado HTTP de la API

Código Significado Motivo Común
200 OK Petición exitosa Retorna el objeto JSON con las cotizaciones actualizadas.
401 Unauthorized No autorizado Falta la cabecera `X-API-Key` o la clave no existe o está desactivada.
429 Too Many Requests Límite excedido Se superaron las 10 peticiones en la ventana de 1 minuto.
500 Server Error Error interno Excepción no controlada en el servicio.
